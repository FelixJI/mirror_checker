# 光学核心:符号约定、正向仿真与回放求解(PR-02)

本文件是 `python/mirror_core/optics/` 的规范说明:坐标与符号约定、
独立正向光线模型、回放求解过程、显式近似与误差预算、验收证据。
数学过程对齐上游 OpenCSP 固定提交 `356e3a9`(对照表见
[upstream.md](upstream.md))。

## 1. 坐标系与符号约定

| 量 | 约定 |
| --- | --- |
| 镜面参考系 M | 原点为名义镜面参考点;`+z` 指向相机与屏幕一侧 |
| 表面表示 | 高度场 `z = h(x, y)`(米) |
| 法线 | `n = normalize(-dh/dx, -dh/dy, 1)`,`+z` 分量为正、朝相机 |
| 斜率 | `slope = (dz/dx, dz/dy) = (-n.x/n.z, -n.y/n.z)` |
| 屏幕米制坐标 | 原点在屏幕中心;`x = (u-0.5)·W`、`y = (v-0.5)·H` |
| 屏幕分数坐标 | `u, v ∈ [0,1]`,有效发光矩形内;u 自左向右、v 自下向上 |
| 相位 | 弧度;解包结果为屏幕宽度分数(无量纲) |
| 强度 | `[0,1]` 归一化灰度(显示端值域缩放另行应用) |
| 条纹图案坐标 | 幅角沿图案坐标反向增大:`(1-s)·period·2π - k·π/2` |
| 距离语义 | DistanceOpticScreen = 镜面参考点(M 原点)到屏幕中心的距离 |

相机为针孔模型,光心在 `+z`,光轴沿 `-z`;像素 `(列 i, 行 j)`,
列向 `+x`、行向 `-y`,按像素中心 `(i+0.5, j+0.5)` 采样。

## 2. 条纹编码与解码(`optics/fringes.py`)

上游 `Fringes.get_sinusoids` 与 `image_processing.unwrap_phase` 的
公式移植(零依赖):

- 周期序列 `from_num_periods(4) = [0.9, 4, 16, 64]`(4^k,首项 −0.1);
- 每周期 4 步相移 `k·π/2`,帧序 y 方向在前、x 方向在后;
- 单帧强度 `cos((1-s)·period·2π − k·π/2)/2 + 0.5`;
- 解码 `atan2(c2−c4, c1−c3)`,多频解缠
  `f = 1/period; A = x − f/2; wa = mod(A+f, f); x = A + mod(w−wa+f, f)`。

解码对常数偏置与线性缩放不敏感(差分相消)。**与上游的差异**:
上游对 y 轴应用 `uy = 1 − unwrapped`、x 轴直接取 unwrapped,该翻转
与其相机—屏幕成像几何(经镜面观看屏幕,一轴镜像)绑定;本仓库正向
模型按真实光路编码,两轴统一 `coord = 1 − unwrapped`,几何翻转由
光线追踪自然产生,不靠解码端补翻。

## 3. 独立正向光线模型(`optics/forward.py`,真值生成)

逐像素:相机射线 → 高度场求交(定步二分,72 次迭代,确定性)→
解析法线反射 → 屏幕平面求交;反射点落在屏幕矩形内才计入活动像素。
输出:射线方向、模型交点(`point_geometry_provenance=
model_intersection`)、解析法线、屏幕 `(u, v)`、两组条纹强度。

表面族(`optics/surfaces.py`):平面、倾斜平面、正/负柱面(可换轴)、
正/负球面(精确 sag)、鞍形、低频二次 + 波纹;各提供解析
`height/gradient/hessian`。真值表面的解析法线/Hessian 是交叉验证的
独立基准——不用求解器自身输出反推(实施方案 PR-02 边界)。

## 4. 回放求解(`optics/solve.py`)

输入只有:射线方向、屏幕几何、条纹强度、名义基准平面。过程:

1. 解码强度 → 屏幕 `(u, v)` → 米制屏幕点 S;
2. 镜面点 X:第 1 轮取射线 ∩ 名义基准平面;第 2、3 轮取射线 ∩
   上一轮拟合面(对齐上游 `SlopeSolver.fit_surface` 外循环);
3. 法线 `n = normalize(normalize(C−X) + normalize(S−X))`(角平分线),
   斜率 `slope = (−n.x/n.z, −n.y/n.z)`;
4. 斜率场按全阶多项式(默认 4 阶,项序对齐上游 `poly_terms`)普通
   最小二乘拟合,系数积分合成为面形
   `z = cx·x + cy·y + cxx·x² + cxy·xy + cyy·y² (+ 高阶)`。

### 4.1 显式近似与限制

- **深度-斜率耦合**(单目偏折固有):仅凭(射线, 屏幕对应)无法
  确定镜面点在射线上的位置。本模块以名义基准平面固定该自由度
  (案例中即真实基面),再经拟合面迭代收敛。迭代后法线角误差见
  §5;基准平面偏离真实约束 1 mm 时,法线出现 >10× 的可测系统偏差
  (`test_reference_plane_must_match_external_constraint`)——这是
  "深度自由度必须由外部观测固定"的量化体现。
- **高度常数不可观**:斜率场积分留下 `z0` 自由度,固定为 0 并在
  导出中显式记录;不得当作实测高度截距。
- **不扣除趋势**:拟合不去平面、不减最佳拟合二次面;被去掉的量
  (若有)必须另行保存(实施方案 §6.4)。验收"全局二次项不被去掉"
  由球面案例检查。
- **波纹的投影泄漏**:正弦波纹的斜率向低阶多项式投影会轻微污染
  二次系数(ripple 案例 cxx 相对偏差 −5.75%,预算 ≤15%);波纹本体
  保留在斜率残差场中(残差幅值 ≈ `amp·2π/λ`)。这正是 §6.4
  "必要时增加局部残差模型"的原因;提高拟合阶数会缓解但小孔径下
  法方程在 6 阶以上病态(显式报错,不给坏系数)。

## 5. 验收证据(2026-11-22,案例级场景实测)

场景:48×32 像素、f=64 px、相机 z=0.18 m、屏幕 0.32×0.22 m @ z=0.25 m,
孔径 ±0.07 m;求解 4 阶 + 3 轮迭代。

| 案例 | 法线角误差 max (rad) | uv 解码误差 | 二次系数相对偏差 |
| --- | --- | --- | --- |
| plane | 2.0e-16 | 1.7e-16 | <1e-15(机器零) |
| tilted_plane | 1.6e-16 | 1.7e-16 | <1e-15;一次项=tan 倾角 |
| cylinder_pos/neg | 1.0e-08 | 1.7e-16 | <1e-3 |
| cylinder_y(90°) | 4.2e-09 | 2.8e-16 | 主轴正确互换 |
| sphere_pos/neg | 9.5e-09 | 1.7e-16 | <1e-3,cxx≈cyy |
| saddle | 2.4e-09 | 2.8e-16 | cxx≈−cyy |
| ripple | 5.5e-07 | 1.7e-16 | −5.75%(预算 15%) |

验收项对应:倾斜平面不产生假曲率(机器零)、90° 方向变化可识别
(主轴互换 >100:1)、全局二次项保留(球面 cxx≥0.5×期望)、单位
明确(导出 JSON 与本文件 §1)、解析交叉验证(上表角误差,光滑面
≤1e-7 rad)。全部断言在 `tests/python/test_optics_solve.py` 与
`test_optics_cases.py` 自动执行。

## 6. 与上游实跑对比(人工证据,2026-11-22)

按 [upstream.md](upstream.md) 的步骤在临时 venv 提取并运行上游文件。

## 7. 导出物(`mirror_cli simulate`)

`python -m mirror_cli simulate --case sphere_pos --output DIR` 生成
(字节级确定,两次运行逐字节一致):

| 文件 | 内容 |
| --- | --- |
| `case.json` | 案例定义、场景、表面参数、基准平面、条纹与求解配置、上游来源登记 |
| `forward.json` | 逐像素相位强度序列、屏幕 `(u,v)`、模型交点、解析法线 |
| `replay.json` | 解码坐标、解算交点/法线/斜率、拟合系数与残差 |
| `verify.json` | 交叉验证数值与验收项判定(不通过则命令返回非零) |

字段形态对齐实施方案 §8.2 的每站保留项(`model_intersection`、
屏幕归一化对应、相机射线、法线),为 PR-07 的真实会话适配预留
同构接口。
